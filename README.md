# Business Analytics Projects – Ahmad Faraj

This repository showcases applied economics and business analytics tools built using Python to solve real-world operational problems for small businesses.

## Overview

These projects focus on translating economic theory into practical decision-making systems, including pricing optimization, labor efficiency analysis, and cost modeling.

## Projects

### Pricing Assistant
A Python-based pricing tool that models:
- Cost of goods sold (COGS)
- Labor inputs
- Overhead allocation
- Profit margins

Generates breakeven and profit-optimized pricing recommendations.

---

### Shift Planner
A workforce scheduling and labor analysis tool that:
- Builds weekly employee schedules
- Tracks wages and availability
- Calculates labor cost and labor as a % of revenue

---

### Service Cost Calculator
A cost-per-client and profitability system that:
- Tracks fixed and variable expenses
- Models overhead distribution
- Includes equipment amortization
- Calculates true service cost and pricing recommendations

---

## Tech Stack
- Python
- Tkinter / ttkbootstrap
- JSON data storage

## Key Focus
Applying economic and financial concepts to build tools that support real business decision-making.
