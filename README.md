# Business Analytics Projects – Ahmad Faraj

This repository contains applied economics and business analytics tools built using Python to solve real-world operational problems.

## Projects

### 1. Pricing Engine
- Models COGS, labor, overhead, and margins
- Generates breakeven and optimized pricing

### 2. Shift Planner
- Workforce scheduling tool
- Calculates labor cost and labor % of revenue

### 3. Service Cost Calculator
- Tracks overhead and equipment amortization
- Computes cost per client and profitability

## Tech Stack
- Python
- Tkinter / ttkbootstrap
- JSON data storage
